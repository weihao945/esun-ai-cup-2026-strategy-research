# 陳韋豪｜策略研究與團隊討論 v1

整理日期：2026-10-14。資料凍結／讀取時間：2026-10-14 21:20:27 +08:00。

用途：下次小組會議比較與整合；這是研究摘要與決策設計材料，不是官方ETF策略交件，也不是已能上場的完整Agent。以既有v4、v5及公告查核成果摘錄，沒有新增回測或調參。

## 先看結論

- 已研究15種廣泛窗口方法，另有6種僅兩年同季的公告原型，以及3種v5開賽前資訊調權變體；樣本、版本及比較條件不同，不能當成24種同等成熟的策略。
- 目前沒有方法通過完整改良門檻，尚未證實某方法最佳。保留A動能等權作比較基準；A溫和動能＋小額調整略過可作非等權研究候選，尚非團隊定案。
- v5財務、營收及組合調權均未證實優於A。兩個歷年同季起點的好結果不代表普遍有效。
- 公告原文判讀已有案例及資料擷取查核；尚未完成完整LLM公告調權績效驗證，也未完成官賽合規與交件驗證。

## 1. 我想解決什麼問題

在約24個交易日的競賽中，先用可重現的資料規則選股，再研究買進多少、多久調整一次，以及加入法人、低波動、財報、營收或公告是否真的有幫助。重點是把可解釋的決策規則交給Agent，而不是每天由人指定股票。

這份報告呈現歷史研究，不是2026當前買股清單或獲利預測。官方賽期與執行規則仍以最新官方文件為準。

## 2. 已做的方法，白話怎麼理解

| 類別 | 已做的方法 | 要回答的問題 |
|---|---|---|
| 參考與基準 | REF流動性等權靜態；A動能等權 | 簡單持有能做到什麼？近期較強的股票是否值得追蹤？ |
| 選股條件 | B動能＋法人；C動能＋低波動 | 資金動向或較低波動，能否改善動能選股？ |
| 換股頻率 | AH、BH持有24日不換股 | 換股帶來的改善，是否足以支付成本？ |
| A配置變體 | 溫和動能、等權／逆波動各半、100%逆波動、溫和動能＋小額略過 | 選同樣股票時，怎麼分配金額與減少微調？ |
| 獨立選股對照 | 五日反轉、純法人、純低波動、純財務、純營收 | 單靠這些資訊，是否比A更有幫助？ |
| 開賽前資訊調權 | 6種兩年同季公告原型；3種v5財務／營收／組合變體 | 選股維持A，只改權重，是否能利用開賽前已知資訊？ |

前五列共15種廣泛窗口方法（含A控制），不是每種都有650個有效窗口。A有535個有效窗口；重疊窗口不能當成535次獨立實驗。較早初版、v3、v4不能混用數字。

## 3. A基準與目前候選規則

| 步驟 | 研究中採用的規則 |
|---|---|
| 資料範圍 | 沿用目前官方150檔名單回看歷史，並套既有資料完整性與公司行動排除條件；有歷史名單偏誤 |
| 選股 | 用前一交易日已知的20日、60日調整後報酬，分別做股票間排名後平均；選前25檔，同分按代碼排序 |
| A控制配置 | 目標投入90%，25檔等權，每檔目標3.6% |
| 非等權候選 | 按動能排名溫和配置，初始目標由4.5%遞減至2.7%；既有小額略過版本門檻為0.5%NAV，正式規則仍須核對引擎細節 |
| 調整與期限 | 每5個交易日檢查／調整；各窗口持續24個交易日；AH／BH為不換股對照 |
| 交易模型 | 整千股、當日均價成交、買賣費各0.1425%、賣出稅0.3%，期末不假設全部賣出 |

以上是研究固定條件，不代表最優參數，也不代表實際每日持股比例必然恰等於目標。

## 4. v4比較：目前能說什麼

最值得帶到會議的訊息是：增加訊號或複雜配置不一定改善費用後結果。要在相同日期比較候選與A，不能跨不同有效日期按中位數選冠軍。

- B動能＋法人平均相對A約+0.079百分點；家族校正區間含零，未證實改良。
- A溫和動能＋小額略過平均相對A約+0.161百分點；24位置家族區間約−0.095～+0.450百分點，仍含零。2026平均差約−0.082百分點、較晚段約−0.144百分點。

- 原研究以24／48位置區塊及多重比較校正處理不確定性；沒有真正未看過的測試集。

## 5. v5新增：開賽前財務與營收調權

選股、24交易日、每5日調整及交易成本沿用A；差別是把當次窗口開賽前可用的資訊凍結，之後不用新公告更新這組訊號。未知資料保持中性，不當利空。

| 變體 | 如何改配置 |
|---|---|
| 正式財務 | 以可核對單季本業利益率變化達±1百分點作方向，權重倍率1±0.25後正規化到90%；較新未解析或更正資訊保持中性 |
| 營收 | 當時可用、45日內且月份落後1～2月的MoM／YoY同向訊號，以既有倍率調權；缺資料中性 |
| 組合 | 50%溫和動能配置＋25%正式財務配置＋25%營收配置，沒有新增倍率搜尋 |

| v5方法 | 同日期窗口 | 平均相對A差（百分點） | 24位置校正區間（百分點） | 2026平均差（百分點） | 結論 |
|---|---:|---:|---|---:|---|
| 開賽前正式財務調權 | 535 | +0.018 | -0.077～+0.148 | -0.076 | 未證實改良 |
| 開賽前營收調權 | 535 | -0.027 | -0.152～+0.078 | +0.004 | 未證實改良 |
| 動能／財務／營收組合調權 | 535 | +0.071 | -0.084～+0.219 | -0.065 | 未證實改良 |


三種都沒有通過改良認定。正式財務與組合方法在2024、2025兩個同季起點較A好，但全期／2026結果不一致，不能只挑兩個點宣稱有效。財務、營收、自結、更正與法說的覆蓋仍有限；這不是完整公告或LLM模型。

## 6. 讀公告後，我學到的事

以下為2025歷史開賽前案例，不是目前股票推薦：

| 案例 | 看起來的訊號 | 原文查核帶來的提醒 |
|---|---|---|
| 南亞科 | 舊Q2本業仍虧損 | 10/13已公開Q3本業轉盈；DB有法說摘要，原關鍵字漏取。不能把舊季資料當最新現況 |
| 群聯 | 本業利益率改善、營收成長 | 淨利卻下降，必須拆解獲利來源；未讀到明細前不能自行說是匯損 |
| 景碩 | 營收成長 | 毛利與本業利益率下降，不能只因營收正成長就加碼 |

2025 A初始25檔已做資訊新鮮度查核；原文存在但中文年份、單位或標題格式造成漏解析。這些更正不能只替有利個股不對稱補入回測。質性判讀已有成果，既有資料也已有LLM歷史輸入包；仍不等於LLM決策品質、穩定性與調權收益已通過驗證。

產業另做過歷年同季指數觀察，屬背景研究；指數口徑不是本組150檔可交易策略，未直接轉成產業加碼規則。

## 8. 帶到會議一起決定

1. 隊友是否同意以A動能作共同控制，再比較各自新增的決策依據？
2. 非等權配置要先保留簡單候選，還是等新資訊調權有更強證據再採用？
3. 公告／新聞在第一版扮演風險與反證檢查，或允許在固定規則內影響權重？
4. DB的更新時點、原文解析、缺漏與更正由誰維護、如何標示可信度？
5. 誰負責規則檢查、Agent整合、DataPack／D-Plan及交件主備安排？

我的會議提案：先把策略解釋與資料品質做清楚，保留簡單控制；沒有證據就不宣稱複雜版本更好。這是提案，尚未替團隊決定。

## 9. 如何交給Agent（設計草稿，尚未實作認證）

資料品質檢查 → A候選排序 → 原文／財務／營收支持與反證 → 按已確認規則決定續抱或調整 → 程式計算權重與整張委託 → 合規與引用鏈檢查 → D-Plan。

公司事實、推論與操作決策分開；未知不得填造，缺少有效資訊不自動解讀為利空。Agent須留下來源與時點、理由與反證；數字與硬性限制由程式檢查。人工撰寫設計文件，正式每日決策由Agent自主產生。
