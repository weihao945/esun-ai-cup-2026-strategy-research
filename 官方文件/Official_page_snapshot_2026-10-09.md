## FAQ Q1 如果某天沒有繳交「Agent決策報告及交易書」會怎樣？

將記警告一次，將以前一日之投資組合計算淨值；警告次數累積達三次者，主辦方將取消該隊伍參賽資格

## FAQ Q2 本競賽允許哪些方式讓AI Agent產生當日Agent決策報告及交易書?

本競賽允許參賽隊伍透過 API 呼叫外部大型語言模型服務（如 GPT、Claude、Gemini 等），也可搭配各類 Agent Framework 或其他合法開發工具進行系統建置。目前競賽未限制特定模型或 API 的使用，亦無須事先申報。
 惟參賽隊伍須自行設計 Agent 的分析流程與決策邏輯，並確保每日投資決策係由 Agent 自主產生，不得由人工直接介入交易內容。

## FAQ Q3 通過初賽的參賽隊伍須繳交哪些項目進行複賽資格審查?

1. AI Agent 完整程式碼。並一併提供 Skill、Prompt、Rules、Workflow、設定檔及相關工具程式。

2. README.md。內容應說明：Agent 投資策略核心、投資組合建構與調整邏輯、Agent 技術架構與執行流程、使用之模型、工具及外部資料來源、Agent 自主決策機制。

3. 其它足以說明 Agent 實際運作方式之必要檔案。

## description

## 競賽題目



參賽隊伍扮演投信基金經理人角色進行操作，每組以 **新台幣 10 億元** 為初始的虛擬本金來自組一檔台股 ETF。標的池固定為 2026 七月底時台股**上市市值前 100 大**＋**上櫃市值前 50 大**個股（詳細個股清單請見**參考文件下載專區**）。



參賽隊伍須**自行開發 AI Agent**，並透過如蒐集、分析外部資料源等方式後作為Agent建構、調整投資組合之依據。投資決策須由AI Agent自主產生，不得由參賽者以人為方式直接決定或介入交易內容。

## procedure

初賽為期 **24 個交易日**。每`交易日開盤前一日 19:30 ~ 該交易日上午 08:55` 為繳交收件時間，成交價以當日均價計算。



每日須繳交文件：**當日Agent決策報告及交易書**(每日每隊伍提交次數以25次為限，如超過次數系統將會阻擋提交)，當日 19:00 可以在「**Agent基金經理人績效排行榜**」查看所屬隊伍當日最新之投資組合淨值表及目前績效排名。

## competition_rules

### 交易限制



- 持股需在 **20–30 檔**，其中台積電(2330.tw)持股佔投資組合淨值上限25%，其餘個股持股佔投資組合淨值上限10%。

- 現金部位每日須小於投資組合淨值之 **25%**。

- 交易決策僅限台股現股交易，不可進行融資、融券、借券、放空、當沖交易；交易單位僅限整股交易，不進行零股交易。

- 初賽之交易之手續費、證交稅依照現行規定計算，分別為0.1425%、0.3%，將於現金部位中扣除。

- 禁止參賽隊伍之投資組合持股前10大與目前市面上流通之各檔主動型ETF前10大持股個股之「主動投資比率」(Active Share)小於20%。
