# E.SUN AI CUP 2026 Strategy Research

本儲存庫專門保存 **玉山 AI CUP 2026** 的策略研究，選股範圍、24交易日期間、持股數、權重、成交與交易成本均以本次競賽規則為研究背景，不應直接視為一般實盤交易系統。

## 研究範圍

價量資料涵蓋2016～2025；主要比較2019～2025的共同有效日期。策略包含動能、法人、均線強度、初始持有與五日調整，統計同時呈現正報酬勝率、跑贏含息大盤的勝率及費後期望。

目前方向為：賽前重視選股與配置、賽中控制換手、證據充分才例外調整。停損與降曝險觸發尚未全部驗證；沒有保證最佳策略。

1. 以日期稽核檔的 `included_indices` 選取同912個窗口，不混用舊935或其他分母。
2. 依原策略快取與含息TAIEX配對計算；未知公司行動或缺價不填0。
